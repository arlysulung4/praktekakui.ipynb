Deskripsi

Proyek ini merupakan tugas praktikum yang bertujuan untuk memahami proses akuisisi dan manajemen data, mulai dari pengumpulan data hingga penyajian hasil analisis menggunakan Python.

Tujuan

- Memahami proses pengumpulan data.
- Mempelajari penyimpanan dan pengelolaan data.
- Melakukan pembersihan dan transformasi data.
- Menganalisis data untuk memperoleh informasi.
- Menyajikan hasil analisis data.

Tahapan Data Science Lifecycle

1. Acquisition: Mengumpulkan data dari berbagai sumber.
2. Storage: Menyimpan dan mengatur data dengan baik.
3. Cleaning: Membersihkan data kosong dan duplikat.
4. Transformation: Mengubah format dan tipe data.
5. Analysis: Menganalisis data untuk menemukan pola dan informasi.
6. Delivery: Menyajikan hasil analisis agar mudah dipahami.
